## 解释与下一步

累计运行涉及统计事件所有权/每日域名、客户端 IP、共享 QUIC 背压、UDP、主机名以及内存快照发布正确性。构建器保留 11 个 runtime 路径和锁文件身份；新增 snapshot_sequence 在基线中显式记 null，其余输入缺失仍失败。这是累计比较，不能把 H3 MISS 的 −0.76% 直接归因某一项，也不能把旧组件百分比相加。

结果说明目前这些局部 ns 级减少尚未改变整条请求的主要开销。下一步结合实际 ready phase poll 与四目标系统调用计数，追查配置快照、分配、头处理和调度/读写粒度；已有裸 Pingora 控制还表明 Edge 业务路径和框架基础成本均需继续分析。不会仅凭 inclusive 火焰图百分比删功能或宣称 XDP/io_uring 一定可以补足差距。

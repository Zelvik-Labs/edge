# 小头表的客户端 IP 回退候选

当前请求过滤包含头表查找成本。本地/私有来源的默认回退最多探测十二个固定头，普通三字段请求也做同样的十二次查询。
候选仅对不超过四字段的头表尝试扫描：保留最高优先级头的原查询，再按相同优先级选择扫描结果。
重复头只看该字段的第一个值，非法/空值继续按原解析器处理；公有来源保持直接返回，大头表保持原查询循环。

调整后的实现已进入性能分支 `20e56ff`，未部署，也没有节点收益结论。
原函数及 IP 解析/规范化原样取自不可变源码；Session 仅替换为只读头表视图，不包含 Pingora 会话与网络成本。
组件将覆盖全部十二头的优先级/重复值、非法字节、IPv4/IPv6 与映射地址，并做确定性生成输入差分。
普通无转发、最高优先级、其他转发头、公有来源、大头表及重复非法值分别计时，分配和计时分开。

本地只生成锁文件和检查格式，Rust 编译、差分与八轮配对测量交给 GitHub Actions。
任何场景退步均保留，不更改信任边界、不增加 IP 来源、不提前采纳重复字段的后续值。
已修复项和未解决的整体差距仍见总报告。经审批的功能降级：无。

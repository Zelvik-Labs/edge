# Zelvik-Edge 0.1.0

这是 Zelvik-Edge 的首个产品版本。它从 `cloud-node-rust 1.2.2` 一次性导入，产品版本与上游版本分开计算。

## 版本来源

- Zelvik 产品版本：`0.1.0`
- 上游项目：`cloud-node-rust 1.2.2`
- 上游提交：`631e5c76cc5605e748dc0230ffc019053b852f80`
- 兼容谱系：`cloud-node-rust-v1`

## 迁移说明

从 `cloud-node-rust 1.2.2` 安装时，这是一次产品迁移，不是 SemVer 数值升级。安装器必须先备份旧二进制、systemd unit、配置和数据，再安装 Zelvik-Edge，并记录迁移来源。现有配置和数据格式保持兼容；完成验证后才允许切换服务。

后续 `0.1.x` 仅用于 Zelvik-Edge 的 bug/security 修复；新增兼容能力进入 `0.2.0`，控制面合同稳定并完成生产门槛后再进入 `1.0.0`。

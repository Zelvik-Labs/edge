# Zelvik-Edge 26.10.4.8

本版本将内存治理与指标生命周期修复合并到正式 Edge 主线。

## 主要变化

- Memory Governor 保持连接建立、已建立流量和控制面资源优先，限制低优先级结构的增长。
- Mace KV 升级到 0.2.0；Metrics 与 Telemetry 使用明确的格式检查和 fail-fast 初始化。
- Bandwidth 窗口交接与 producer state 使用原子 durable handoff，历史 Metrics retention 使用有界增量扫描。
- ServerMetrics live、候选、retired 和旧请求引用纳入统一家族容量上界；容量不足时在配置副作用发生前拒绝新配置，保留旧配置。
- 退役指标在 Persistence、Bandwidth、Daily 三个 Consumer 确认最终 fingerprint 且旧引用释放后，由后台扫描回收，无需等待新的配置推送。
- NodeTask 的本地准入拒绝（ServerMetrics 家族容量或内存治理）不再向控制面上报结果，任务保持 pending 由后续轮询重试；确定性失败仍按原语义上报失败并记录错误。
- HTTP/2 连接达到最大生命周期后只拒绝新流、不打断已接受的响应；拒绝本身不再刷新活动时间，连接不能靠持续开流绕过生命周期上限。

## 兼容性与限制

- Mace 0.2.0 数据格式与 Mace 0.1.x 不兼容。普通启动不会删除或自动迁移旧数据库；遇到旧格式必须显式处理开发数据或使用已批准的迁移路径。
- 本版本的内存测试证明了受影响结构的容量边界和回收条件，不等同于 7/30 天 RSS 稳定性证明。Mace PageMap 高水位、allocator 保留页、Client-Agent 历史身份等长期边界仍需持续观测或后续协议支持。
- Bandwidth/Daily 仍有尚未进入 durable spool 的进程内窗口状态；进程崩溃时不能把这部分状态宣称为已交付。
- 组件版本按 `YY.MM.PATCH[.x]` 管理；Cargo 保持三段 `26.10.4`，本次完整产品版本和 tag 为 `26.10.4.8` / `v26.10.4.8`。

发布包、SHA256 清单和多架构 GHCR 镜像由 tag 触发的 Release workflow 构建；镜像复用已验证程序包中的同一份二进制。

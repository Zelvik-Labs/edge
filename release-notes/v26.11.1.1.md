# Zelvik Edge 26.11.1.1

Zelvik Edge 是独立的 CDN 边缘产品，维护自己的产品路线和发布周期。cloud-node-rust 仅作为历史代码来源记录；本产品不是其替代品或重命名发行版。

本版本整合此前性能分支的缓存、HTTP/H3、统计、内存治理、SNI/TCP、UDP 与 XDP/AF_XDP 改动，保留实验后端的明确选择和边界。

- HTTP 下游采用 1460B 写缓冲，保持原生 TCP/sendfile 类型与 socket 身份，并计入内存估算；读缓冲保持 0。新增刷新、部分写入取消恢复和文件响应顺序回归。
- 缓存减少重复 Range 全对象预检查、临时头表和键准备；保留 Range、发布、墓碑和失效语义。
- H3 回源连接池和活跃请求上下文分离，修复排空/替换生命周期；共享 QUIC 的多个写等待者独立获得唤醒，并保留接收与队列资源约束。
- SNI 分片解析减少不完整输入分配，TCP/SNI 转发保留部分写入和取消时已传输字节的统计。
- 按消费需求准备自定义指标上下文，转移已有维度所有权，复用域名数据；不关闭内置业务统计。
- 内存治理以独立序列发布一致快照；空 WAF 状态避免预分配大表；XDP 自动亲和性使用实际允许的 CPU 编号。
- 修复性能观察器的线程退出、历史客户端来源、host cgroup 配额读取和源站参考边界；保留原始归档、失败及负向数据。

默认 H3 后端仍为共享 Quinn。tokio-quiche、原生 Quinn 与 io_uring 实验保留其显式启用方式，不把候选组件收益或部分条件领先解释为完整 Edge 超过 nginx/OpenResty。

## 验证与限制

发布运行时代码 `2c32f24` 通过完整项目/Pingora check、Clippy、1375 个库用例、16 个二进制用例、110 个集成用例、827 个 Pingora 用例及 32 组原生节点组合和网络清理；有界状态与持久化恢复也通过。启用 `h3-quiche` 的独立检查通过 check/Clippy 和 1383+16 用例。项目五个性能探针和 Pingora 两个既有探针保持显式 ignored。最终报告为文档提交，生产文件与该验证候选核对一致。

独立前后节点对照覆盖 H1/H1-TLS/H2/H3 × HIT/MISS/OFF × 复用/新建连接 × 四目标 × 四轮：384/384 格、7,240,745 次成功响应、零传输错误，256 个 Range 和 48 个错误 CA 控制通过。原始 ZIP、实际输入二进制和逐请求记录已独立复算，证据作为本版本附件保存。

固定缓冲候选的 H1/H1-TLS HIT/reuse 吞吐配对中位分别提升 19.01%/18.37%，CPU/响应均下降约 15.58%；H2 HIT/reuse 提升 2.15%。H2 MISS/reuse 为 −0.52%，H3 HIT/fresh 为 −1.95%，全部 26 个负向配对吞吐轮次保留。测量针对固定候选 ELF，最终安装包按发布标签和各 ISA 参数另行构建；不把候选 RPS 冒充最终包的直接测量。

多数 H1/H2 条件仍低于 nginx/OpenResty，H3 HIT 客户端接近预算。历史 QUIC 客户端互操作失败、云短窗口和客户端/源站预算限制在各性能报告保留；没有 24/72 小时长期稳定性或整体超越竞品的结论。没有经审批的功能降级，也未部署到 RKE。

见 [下游缓冲接入](../docs/performance-downstream-buffer-2026-11-04.md)、[全程序性能进度](../docs/performance-program-wide-2026-11-04.md) 和 [架构对照](../docs/performance-architecture-review-2026-11-04.md)。
